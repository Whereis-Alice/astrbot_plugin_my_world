# 安静翻消息

[文档目录](README.md) · [生活工作区](life-workspace.md) · [与 Anamnesis 配合](memory-compatibility.md)

她可以在空闲时拿起手机，或在有电脑的地方看看近期消息。也许一句话让她想到自己的生活，也可能看过就放下。这里关心的是 **她读完后的感受**，不要求她总结群聊或找人接话。

例如，别人聊到窗边开花，她可能想到“也想在自己的窗边慢慢养一盆”；这只是一点个人感想，不代表她已经买了花，也不会自动替她创建任务、许下约定或发消息。

## 怎样开启

1. 打开 **生活 → 牵挂 → ⋯ → 节奏与预算**，展开 **安静翻消息**。
2. 开启“空闲时可以安静翻消息”。这项功能默认关闭。
3. 按原有人设选择“她有一部手机”，或勾选有电脑的地点。未提供设备时不会安排这项活动；电脑只在所选地点可用。这里的设备属于角色世界，不需要服务器电脑、浏览器或沙盒。
4. 按需要限制可翻阅的会话。不选表示同一共享生活组内已启用的会话；选择后仅使用所选范围，不跨生活组。
5. 点击“应用设置”，再点顶栏“保存”。有独立生活配置时，先在顶栏选择相应编辑范围。

开启后，她在没有其他活动或未完计划的空闲时间偶尔选择浏览。睡眠、困意、精力、日程与重要经历优先；开启设备不意味着她会一直用它。关闭“自主搭话”后，这项安静活动仍可进行。插件或实际来源会话停用后，不再读取相应内容。

## 她能看到什么

只使用 **插件实际收到并仍在近期窗口内的文字**。一次读取一个实际会话，不向平台补拉历史，不访问服务器文件或调用电脑工具。媒体已有的文字描述可以随消息被阅读，不会因此再识图、解析视频或下载资源。

| 默认限制 | 数值 |
| --- | --- |
| 阅读窗口 | 最近 6 小时 |
| 每次消息数 | 最多 20 条 |
| 每次正文总量 | 最多 3,000 字 |
| 两次浏览间隔 | 至少 2 小时 |
| 每天浏览次数 | 每个角色最多 3 次，共享生活组共用额度 |

这些是上限，实际内容受已有聊天缓存大小限制。窗口和字数可在“调整阅读窗口”中更改。浏览占用约三至八分钟的角色生活时间，收尾时完整携带当前人设，通常请求一次判断模型，输出限制为 600 Token；判断通道失败可能按现有规则回落。消息字数上限不包含人设，长人设也会计入后台预算。所有请求都使用已有后台并发、超时、退避和每日预算，不增加常驻服务或运行依赖。

浏览有自己的进度。她回过的内容仍可以在空闲时看看；看过的内容不会因此变成“已回复”。没有新内容或只有自己的消息时，不为浏览调用模型。失败或被打断仍保留本次冷却与次数，避免连续重试。

## 感想留在哪里

- **生活 → 今日** 显示正在翻消息的活动。
- **内心活动** 显示她留下的感想、地点和来源会话；“阅读依据”默认折叠，只保留至多两段短片段供核对。没有特别感受时可以不留下记录。
- **模型调用** 可按“翻消息时的感想”筛选，查看原因、结果和 Provider 返回的用量。

普通感想保留 24 小时，到期不再注入或显示，并随生活时钟清理。只有被判断为对自身生活有持续意义、且开启相应选项的感受，才进入生活记忆。记的是“翻阅消息时，我想到……”，保留来源与理由，不保存第二份聊天摘要。

感想可以轻微影响当下心情，单次额外情绪偏移不超过正负 0.02；原有情绪仍照常随时间变化。它不会增加好感、改变身份关系、提取人物事实或词典，也不会改写人设、喜恶和价值观。

## 与正常聊天、聊天记忆的区别

| 机制 | 重点 |
| --- | --- |
| 正常聊天与回合复盘 | 对方正在与她交谈，回复后记录本轮实际互动。 |
| 安静翻消息 | 她在独处时阅读已有消息，只留下自己的主观感受。 |
| Anamnesis 等长期记忆插件 | 保存与检索聊天往事，帮助回答过去聊过什么。 |

已注入的 Anamnesis、RAG 历史记忆块会从阅读材料中剔除，不再当成新消息。人物事实、详细画像与群词典继续按各自原有机制工作。

浏览感想始终保留实际来源。**私聊感想只在原私聊被动交谈相关时参考**，同一生活组的其他群和私聊也不能召回它；群里的感想同样留在原群。普通自主发言、事件结算、角色审视、睡眠整理与自动回访不使用这类感想，不把它们放入主动话题或待发送队列。有意义的长期感想可在原会话的正常回复中相关召回，或通过 `mw_memory_lookup` 查询。

浏览输出只接受感想、小幅心情变化和来源编号。模型返回的发言、工具或任务指令都不会执行。中断、跨日、人设或配置变化、离开原地点、原消息已清除时，过期结果作废；已经开始但被取消的请求不会在重启后重放。清空当前会话上下文也会清掉它的短期浏览感想，生活记忆仍由记忆页面单独管理。

正常 QQ 聊天依旧使用 AstrBot 原生 Agent、工具和发送能力。若其他日程或事件允许主动发言，它们仍按自己的设置运行；安静翻消息本身不触发这些发送。
