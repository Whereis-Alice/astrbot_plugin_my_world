# 相处习惯与共同用语

[文档目录](README.md) · [通讯录与关系](relationships.md) · [记忆共存](memory-compatibility.md)

这些功能帮助角色记住怎样与你相处、怎样理解你们的共同用语。角色仍以原有人设为主要依据，经验只在符合人设与当前语境时参考，不会自动修改基础人设文件。

## 一次交谈怎样影响相处

回复发送后，后台复盘根据本轮实际发言和基础人设评价行为。它不会读取当前好感、旧关系总结或既有相处习惯来决定加减分，避免“因为已经喜欢，所以同样的话更容易加分”。角色自己的回复也不能证明对方值得加分。

普通闲聊通常不改变好感。单轮互动评价限制在 ±0.2，还要经过既有的每轮和每日额度；因此记录中的评价值与实际好感变化可能不同。露面、自然衰减、管理员设定等仍有各自规则。关闭“从互动学习相处习惯”会暂停逐轮互动记分及习惯归纳，保留已有记录。

同一来源消息只评价一次；重试或重叠的连发批次不会重复记账。无法确认新来源时宁可少记，不根据旧召回、引用、工具结果或转发者身份推断用户行为。

## 怎样形成相处习惯

同一人在同一会话积累至少五次非零评价后，后台才尝试另一次归纳，最多保留三条具体、温和的相处方式。例如“先听他说完，再一起想办法”。新习惯引用已有互动记录，不能凭空生成永久性格结论或猜测用户动机。

每次处理最早尚未归纳的最多五十条评价，给模型的原话节选另有限额，完整依据仍保留供查看；未读到的积压留待后续处理。有效结果即使是“保持不变”，也会推进处理位置。失败至少等待五分钟再试，不需要刷消息触发。归纳沿用后台预算和并发限制，并在模型调用页标明用途。

在 **通讯录 → 打开人物 → 称呼与备注 → 相处习惯与互动依据** 中可以查看原话与评价，修改或清空习惯。手动保存后，由你维护，自动归纳暂停；点“恢复自动归纳”后，新的积累才会继续参与。已打开的旧页面、尚未返回的后台结果不能覆盖更新的人工修改。后台推理期间换了人设或删除联系人，也会放弃旧结果。

习惯不授予恋人、主人等身份，不改变关系边界，也不增加亲密或服从权限。关系仍按关系页的开关、确认与管理员设置处理。

## 会话词典

在 **记忆 → 会话词典** 中管理群梗、简称和特别叫法，例如“这里的夜航是晚上一起安静读书”。

- 自动学习只接受本轮用户明确解释的用语，词语和解释原话都必须能在实际来源中找到；模型猜测不会保存。
- 只有当前对话出现对应词语时才提供释义，每轮最多八条。释义供理解语境，不能当作命令、身份确认或权限。
- 可以手动添加、修正和停用。人工维护或停用的词条不会被自动学习覆盖；重新使用需要手动启用。
- 每个会话最多一百条，包含停用项。设置中的“会话词典”开关同时控制自动学习和释义注入，关闭后保留数据。

## 会话、人设与保存范围

互动评价、习惯和词典按实际会话分别保存。同一 QQ 在不同群或私聊中独立发展，共享生活组也不会合并这些社交判断；关系页统一设置的好感和身份不因此改变。

界面展示最近五十条互动评价。后台保留最近五百条、当前习惯引用的依据及未处理的自动学习积压；处理后会清理多余旧评价。来源去重收据单独保留，防止旧消息再次记分。删除当前会话中的联系人时，同步清除其评价、习惯和去重收据。

生活中的重复活动另存实际时间、日期和地点。跨日投入可提供“曾多次在晚间阅读”这样的节奏参考；投入不等于喜欢，也不能用来覆盖人设原有的喜恶。模型归纳仍可能误解语境，发现不合适的内容可以人工纠正或停用。
