# 数据、备份与迁移

[文档目录](README.md) · [返回首页](../README.md)

数据默认保存在 `data/plugin_data/astrbot_plugin_my_world/`，包含世界配置、SQLite 状态库和 `profile_weaver/` 画像目录。备份时建议停止 AstrBot 后复制整个目录；运行中复制数据库应使用 SQLite 备份机制，避免遗漏 WAL 中的写入。

## 从世界插件迁移

本项目历史名称为 `astrbot_plugin_her_world`。首次启动前可设置环境变量 `MY_WORLD_MIGRATE_FROM` 指向原数据目录。已存在的目标数据不会被整份覆盖，先保留原目录备份，迁移后检查地图、会话和几位联系人。

## 从心迹画像迁移

首次启动会继承旧插件的画像、字段锁、审计与备份。核对通讯录中的会话范围和资料后，可停用旧画像插件，只保留本插件。旧插件仍启用时，本插件避免重复注入及注册同名工具，独立的 `mw_profile_lookup` 仍可用。

后续增量同步按字段变化进行。当前插件删除的字段，不会因为旧插件的未变化记录在重启时重新出现；旧插件实际修改该字段后，才作为新的增量来源。

## 更新后检查

自定义地图、动作与档位保持保留。缺少作息模式的配置采用自主作息，需要固定睡眠日程时请在设置中选择固定模式。恋爱、主人等特殊关系缺少自然形成开关时，采用关闭状态；已有正式关系不受影响。十档相处方案需要在设置中主动应用，不覆盖现有档位。

若孤独或无聊已经很高，可等待生活逐步缓解，也可在控制台编辑当前数值。具体历史变化见 [更新日志](../changelog.md)，问题排查见 [常见问题](faq.md)。
