# 与 AstrBot 和其他插件配合

[文档目录](README.md) · [模型设置](models.md) · [记忆共存](memory-compatibility.md) · [开发说明](dev.md)

默认使用注入模式：本插件提供角色此刻的处境、生活和关系背景，聊天回复由 AstrBot 原生 Agent 完成。模型调用、工具循环和消息发送沿用宿主流程。生活后台负责自己的规划与整理，不接管另一套主对话。

## 被 @ 时由谁回复

符合宿主唤醒规则、会话设置与睡眠门禁的消息，继续进入 AstrBot 原生 Agent。本插件在请求前注入生活背景，观察响应、工具结果与发送完成后的实际情况，用于记录和复盘。

其他插件提供的上下文与宿主工具继续留在请求中。被 @ 并不切换到另一套聊天模型，也无需将已安装工具逐个导入世界动作才能调用。

旧配置仍可显式使用接管模式；它自己生成和发送回复，有单独的兼容桥接和限制，不是推荐起点。该模式的开发边界见 [开发说明](dev.md#两个版本开关)。

## 分段回复的节奏

默认聊天的分段、发送、语音替换和表情包处理由 AstrBot 与对应插件决定。本插件里的旧式逐句延迟、引用和连发合并设置主要服务旧接管路径，不代表原生聊天会使用相同节奏。

不要同时开启多套相似的防抖或重发机制。工具已经执行或消息已部分发出时，重新触发整轮可能重复产生结果；本插件不会在后台生活事项中重放这些外部操作。

## 性别与称呼

全局设置的性别影响编辑器、状态输出和模板中她、他或 ta 的称谓；完整角色语气仍以所选 AstrBot 人设为依据。通讯录的称呼、好感和身份有各自职责，见 [关系与好感](relationships.md)。

## 群名片显示什么

启用群名片同步后，优先展示当前动作的执行中文案，其次是地点文案，都没有则使用原名片。模板、最长长度与冷却在群名片同步设置中调整。平台不支持改名时，不能通过世界内行动假装修改成功。

## 谁能用管理指令

修改配置、重置、调试和会话管理等指令需要管理员权限。AstrBot 自己的管理员可管理插件，也可在插件设置中补充管理员账号。只读状态、记忆、回忆和帮助指令不属于管理操作。

编辑器有自己的访问保护。开启公网访问前应设置访问密码，不要在截图或问题报告中公开访问令牌。更多说明见 [编辑器与外观](webui.md)。

## 与其他插件联动

| 类型 | 配合方式 |
| --- | --- |
| 世界书与环境感知 | 使用宿主请求钩子注入内容。本插件保留其他来源上下文；相同信息可能重复，应按需要调整各自预算。 |
| 搜索、天气、生图等工具 | 由原生 Agent 调用宿主工具；不必为每个工具建立虚拟动作。被观察到的天气结果可进入世界天气状态。 |
| 语音与表情包 | 使用宿主响应和发送流程。具体能力依赖已安装插件、配置和平台，不保证任意插件组合都能自动互相识别。 |
| 长期记忆 | 本插件只保存生活记忆，聊天往事交给专门记忆插件，见 [记忆共存说明](memory-compatibility.md)。数据库不会自动合并。 |
| 意图路由 | 可读取只读接口 social_snapshot(session_id) 获取当前社交状态；是否使用这些状态，由对方插件决定。 |

主对话保留原生工具，世界内项目自动推进仅使用允许的安静活动。需要生成真实文件、发送照片、购物或联络他人的事情，以正常对话中的工具实际结果为准。

### 画像迁移与查询

启动时可从同层数据目录中的心迹画像插件继承资料、审计和备份，并按当前隔离设置整理。应先确认通讯录资料完整，再停用旧插件，避免两个插件长期写不同目录。

通讯录按人物展示完整资料，关系与好感在独立页面管理。按 QQ 设置统一起点后，各会话继续独立发展；共享人物起点不代表跨会话共享全部私人经历。

模型可通过 mw_profile_lookup 查询当前作用域内的画像、关系和共同经历，通过 mw_memory_lookup 查询记忆。原有画像工具继续保留兼容能力，详见 [记忆与通讯录](memory.md)。

### 睡眠与日程工具

睡眠门禁可配置哪些消息允许打扰；@、私聊和指令的具体放行按所选规则执行。自主作息决定何时想睡，与宿主唤醒设置分别生效。

插件可向宿主提供 mw_schedule_list、mw_schedule_add 和 mw_schedule_remove。工具过多时，可关闭把日程工具交给模型的配置，编辑器仍可管理日程。

### 图片与语音

图片转述支持持久缓存和并发去重。URL 的查询参数可能决定实际图片，因此会保留在缓存指纹中；仅临时签名变化也可能重新识别。旧的 URL 缓存不会错误覆盖新图片，内容型图片缓存仍可复用。

语音转文字依赖 AstrBot 配置的转写能力。图片缓存不意味着已经有统一的音频、视频理解流程；媒体内容不可用时，应明确缺少信息。

### 排查联动问题

先在编辑器查看本轮状态和模型调用原因，再检查 AstrBot 日志及对应插件设置。模型调用页中，原生聊天只观察最终响应，宿主内部中间轮次、重试和全部工具 Token 不一定可见，见 [模型调用与用量](model-calls.md)。

后台活动不保证经过其他插件的全部聊天钩子。关闭自主搭话只控制主动发言，不会暂停所有生活；日程和事件的发言另有开关，见 [自动生活](autonomous-life.md)。
