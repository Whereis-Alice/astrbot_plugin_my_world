# 角色的恢复方式

[返回首页](../README.md) · [自动生活](autonomous-life.md)

## 充电、维护与冥想

在设置的“作息与夜晚”中，将作息模式改为“无需睡眠，通过活动恢复”。明确选择适合的恢复动作，或留空让系统选择可用的恢复活动。模式是明确的生理约束，不靠角色名字、物种或动作名称猜测。

默认精力低于 25% 安排恢复，目标为 85%。动作必须是启用的持续活动，有净正向精力效果、满足前置条件与次数限制，且地点可达。自动恢复不选择真实工具、指令或需要对他人执行的动作。正常疲劳等手头活动收尾；严重透支会按生活优先级暂停普通活动，关键事件与行走仍按已有规则处理。地点专属动作会先走到允许地点。

例如艾拉的充电椅动作可以设置为：

| 字段 | 示例 |
| --- | --- |
| 恢复类型 | 恢复精力（restore） |
| 类型与执行方式 | 持续活动、模板 |
| 地点限制 | 充电椅所在卧室 |
| 时长 | 模型决定，最短 900 秒、最长 2400 秒 |
| 每分钟效果 | energy: +0.025 |
| 完成后效果与触发 | 可留空；无额外触发 |

这只是效果示例，恢复速度应结合角色设定调整。仅完成后 `energy: +0.12` 也能恢复，但需要整段完成才获得这部分奖励。每分钟效果会随着实际活动时间结算，中断保留已经发生的部分；完成时不重复结算。倍数和设值效果在完成时应用一次。

固定时长保持固定；可变时长按恢复速度估算，遵守上下限。单段不足时可继续恢复，到目标后结束恢复意愿；达到目标且超过最短时间时可以提前收尾。纯模拟、模板、无外部工具及完成触发的显式恢复动作可结算离线经过的时间，不补发消息。

无需睡眠模式不累计困意，不安排整觉、小睡或熬夜惩罚。切换时取消旧的待睡状态，不补发睡眠完成奖励。安静时每天仍可整理一次生活记忆与人物资料，沿用原整理开关和首次等待时间，失败退避重试；不会生成梦境。直接聊天照常响应。

v4.38.0 起，日程生成候选与执行器使用同一生理约束；无需睡眠模式不会接收整觉、小睡及其自定义变体。设置页会说明当前编辑范围的模式与优先恢复动作，提醒已删除、停用、不兼容或没有绑定地点的选择。已有世界的作息开关保持原值，需要按角色明确选择。

恢复收益按整段净变化保守估算，完成奖励保留原语义；低精力时，名义上增加精力但实际净耗电的普通活动不会阻止切换去可用的恢复动作。离线已到期的被动恢复先完成，再结算之后的清醒时间。后台思考接回时合并已结算分钟数，正常推进不会被误判为换了动作，也不会重复领取效果。

## 生成或自建睡眠动作

动作编辑器中的恢复类型包含：自动识别、非恢复、整觉、小睡、恢复精力。生成器也支持这些字段。

显式整觉和小睡会进入实际睡眠状态，遵守动作时长，支持唤醒、打断与睡眠历史。显式睡眠动作配置了每分钟精力效果时，就使用该效果，不再叠加内置基础睡眠恢复；未配置则使用基础恢复。旧自动识别模式保留兼容行为。

内置整觉在自主作息下沿用全局整觉范围；自建整觉使用自己的时长范围。小睡候选不可用、次数用尽或地点不可达时，会尝试其它可执行候选。“非恢复”不进入自动恢复候选；仅把名字改成“睡觉”或“充电”不会改变机制。

升级保留已有模式。要让已有角色使用充电，需要先选择无需睡眠模式，并配置实际恢复效果；插件不会擅自替现有世界做这个选择。
