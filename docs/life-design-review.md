# 生活与关系设计审视

[文档目录](README.md) · [自动生活](autonomous-life.md) · [生活事项](life-matters.md) · [Giftia 对照](giftia-comparison.md)

目标是让角色有连续的日子：知道自己在做什么、为什么想继续、什么时候该休息，经历能影响后续选择。主动发言次数不能代表生活丰富程度，更多情绪分数也不能直接产生人格。

## 当前能力与剩余边界

| 范围 | 当前能力 | 仍需改进 |
| --- | --- | --- |
| 地图与移动 | 两层地图、路线耗时、地点和连通性检查，候选按当前启用动作筛选。 | 地点主要提供行动条件，环境长期变化与项目产物之间联系较浅。 |
| 动作与计划 | 持续动作、安静活动、真实截止时刻；独立计划 ID 防止旧动作误推进新安排；跳过、转入待睡与完成分别记录。世界变更按角色自己的地图修复，保留投入并同步运行步骤位置。 | 日程、事件、睡眠、对话和项目仍有各自入口，需要统一决定优先级和续作方式。 |
| 日程与作息 | 每日安排感知已有事项；独立睡眠评估、待睡让位、过劳兜底；休息前检查路线可用并保存工作。 | 自动排程仍需首次开启；偏好尚未形成可解释的周节奏。 |
| 长期事项 | 动机、跨天步骤、阻碍、暂停恢复、阶段核对；额度耗尽不阻塞其他事项，投入按日结算；自发打算失败后有间隔地重试，明确没有新想法时停止追问。 | 自动推进仅使用安全的世界内安静动作，复杂作品和外部操作不能只靠计时证明完成。 |
| 兴趣与变化 | 跨多个日期的实际活动可成为稳定兴趣，影响后续选择。 | 中断活动的兴趣积累、兴趣淡化和日常偏好还可细化；不会自动改写基础人设。 |
| 情绪与需求 | 经历影响心情、精力与需求；独处也有缓解方式，没人回复时降低打扰。 | 主要仍是规则数值，尚未形成充分可核对的“为什么最近更在意某件事”。 |
| 关系与好感 | 身份、好感、距离和越界权限分离；按 QQ 统一起点，各会话以后独立发展；特殊关系默认手动。 | 可以补充基于真实互动的相处习惯，不能绕过身份确认或关系开关。 |
| 记忆与来源 | 原话快照、上下文资格、冻结批次、幂等和修订历史；可选语义召回，失败回退关键词。 | 索引逐步补齐，尚无独立重排、完整事实版本图或跨插件自动去重。 |
| 事件 | 选择、后果、关键阶段与分享策略，事项给关键事件让位；区分动作进行中和已取得结果，静默与其他角色隔离。 | 事件后续与长期项目联系较松散，不能把随机经历堆成无休止的待办。 |
| 宿主与工具 | 主回复使用 AstrBot 原生 Agent，观察工具实际结果；外部操作不在后台项目中重放。 | 原生中间轮次与内部重试不完全可见，最终响应账本不能代表完整工具事务记录。 |
| 图片与媒体 | 持久转述缓存、并发去重、失败短时退避；取消释放等待者，URL 内容参数参与缓存键。 | 临时 URL 变化可能重新识别；尚无覆盖图片、音频、视频的统一按需媒体工作流。 |
| 后台与恢复 | 后台工作按顺序排队、同键去重，容量覆盖每个角色，并发设置可调整；有持久每日预算和失败退避。离线睡眠与醒后时间分别结算，不补造工作进度。 | 部分普通决策仍在状态锁内等待模型，多角色日程仍有串行路径，全部推理锁外提交尚未完成。 |
| WebUI | 人物、关系、生活、模型调用独立页面，卡片展示、次要操作入抽屉，六主题和手机适配。 | 异步操作必须绑定发起会话，后续新增页面也需要保持同样的竞态保护。 |

## 下一步的优先顺序

1. **统一生活取舍。** 各入口先提出意图，再由同一层决定开始、等待、中断或放弃。保存原因和续作位置，让日程、约定、困意和事件彼此理解。这比再加一批活动更重要。
2. **让经历成为温和、持久的偏好。** 例如多次晚间读书后倾向晚上阅读，频繁被打断后把长项目拆小。依据实际收据和跨日观察，保留可撤销记录与人设约束。
3. **让相处有具体方式。** 根据真实交谈归纳“喜欢先听对方说完”等短句，保留来源和人工覆盖。它描述怎样相处，不授予恋人、主人等身份或新权限。
4. **让回忆更准确、可解释。** 在作用域和语义检索之后按需增加重排、命中依据及冲突事实展示，优先减少错认人物和旧事实冒充近况。
5. **完善异常边界。** 对可观察的工具开始、返回和发送结果建立关联，明确部分成功，避免重放。逐步将后台模型改为锁外推理、版本核对后提交，继续拆分多角色日程中的串行等待。

这些是后续方向，并非已经全部实现的功能。当前适合逐步收拢职责，无需推翻 AstrBot 原生 Agent 或重建聊天系统。

## 怎样验收有自己的生活

- 无人聊天时能安静活动、休息、推进可执行项目，不用持续发言维持存在感。
- 同一项目跨天能接续，额度耗尽不拖住其他事项，中断不会抹掉在线投入。
- 安排、实际活动、世界内阶段结果和真实工具成果能清楚区分。
- 能解释为何做、为何暂时放下；异常恢复不补造经历。
- 统一关系起点不抹平各会话历史，共享世界不泄露私人约定。
- 模型不可用时基本生活继续，代价和失败原因可查，允许等待、受阻和没有新想法。
