# 生活与关系设计审视

[文档目录](README.md) · [自动生活](autonomous-life.md) · [通讯录与关系](relationships.md)

目标是让角色的经历连续、行动有节奏、相处有依据。自动生活并不等于频繁发言，也不能把身份关系等同于一个不断上涨的分数。

| 范围 | 处理与设计决定 |
| --- | --- |
| 地图与移动 | 保留两层地图、耗时路径与连通性检查；作为行动发生的空间。 |
| 动作与日程 | 保留持续动作和少量日计划；默认提供安静活动，发言暂停不阻断规则生活。 |
| 作息 | 保留独立睡眠评估、待睡让位和规则兜底，抵达地点时优先兑现待睡决定。 |
| 情绪与需求 | 保留生活缓解和渐缓增长；区别长期好感、此刻心情与临时生气。 |
| 关系 | 分开身份、距离、自然形成权限与越界权限；候选不占正式槽位。 |
| 友谊 | 用跨日期直接交谈和好感发展普通关系，刷屏和露面不代替交谈。 |
| 经历与打算 | 保留人物归属；过期记为未完成，不把计划写成事实。 |
| 记忆整理 | 核对关系原话与确认归属，整理和当场记住共用聊天好感额度。 |
| 事件 | 保留事件选择、后果与分享策略；日程和事件发言各自受开关控制。 |
| 模型与宿主 | 保留 AstrBot 原生 Agent 与工具流程；后台请求限时，单会话失败隔离。 |
| 人物管理 | 通讯录集中展示资料与经历；独立关系页按 QQ 设定统一起点，各会话分别发展，保留差异与历史。 |
| 网页编辑器 | 人物卡片占据主要空间，详情按需展开，工具收进小型工具区；支持手机、深浅主题、键盘操作与规则草稿。 |

## 仍有边界

生活记忆检索主要依靠字面话题与规则加权，完整语义检索、跨插件去重和事实版本图仍值得后续独立设计。没有增加虚构的信任分数或不可验证的人格状态。

证据检查核实的是原文、说话者和交谈位置，不能完全替代语义理解。多人插话导致确认对象不明确时，宁可保留候选。重要身份可保持手动设置。

动作边界主要通过提示词表达，模型输出不具备硬性保证。现实工具由 AstrBot 管理，虚拟经历不代表实际完成了外部操作。自动排程仍需一次性开启，宿主停止运行期间不会完整模拟。
