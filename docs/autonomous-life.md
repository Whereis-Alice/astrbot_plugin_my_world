# 自动生活指南

[文档目录](README.md) · [返回首页](../README.md)

## 一次设置，持续生活

先启用会话、选择人设、检查地图连通性，再挑选适合角色的动作。基础说话、移动、睡眠、小睡与安静闲置动作默认可用；主题动作可按角色开启，或用生成器创建。地图、动作和事件生成会先展示草稿。

希望每天有不同安排，在日程页开启自动生成，配置生成时间、数量与内容模型。它参考当前状态、近期经历和未完的打算，生成当天的一次性计划。地图不会自动重建，生成失败时查看日志与模型设置。

## 没人聊天时

世界时钟、移动和持续活动继续推进。空闲时会观察周围、伸展休息或整理手边的小东西；这些小动作不调用模型、不发送消息，也不逐条写入记忆。可以按人设生成更多闲置动作，并调整持续时间与生活影响。

休息、兴趣和探索会缓解孤独与无聊，数值较高时增长放缓。同一条主动发言没有回应只计一次；她能安静做自己的事，不需要靠不断聊天维持状态。

## 作息

自主作息默认开启。她结合当地时间、精力、清醒时长、最近睡眠、人设与安排，决定何时睡以及睡多久。普通决定会等手头活动收尾，再走到卧室；待睡阶段的自动日程让位，危险事件先处理。

模型不可用、超时或给出无效结果时，按疲劳与清醒时长兜底。默认整觉范围为 6–10 小时，连续清醒达到 20 小时会触发过劳保护。也可切换固定作息。控制台能看最近决定、下次评估与睡眠记录，详见 [作息与节奏](rhythm.md)。

## 安静生活与暂停

关闭顶栏“自主搭话”后，普通自主规划走安静规则，抵达地点后也继续安静活动；作息评估、已安排的生活、情绪和记忆仍可运行。后台并非完全零调用：自主作息、自动排程、事件与睡眠整理有各自任务和开关。

日程提醒、事件分享分别受“日程到点也发言”和“事件发生时发言”控制。只想回应消息时，一并关闭它们。插件总开关、会话停用或停止 AstrBot 会暂停生活；重新运行不会把停机期间的全部活动补演一遍。

## 打算与共同经历

她可以留下想做的事和对具体人的约定，在生活事项页查看跨天步骤、进展和阻碍。被打断后保留已投入时间，阶段结束后核对结果并继续后续。项目和承诺持续保留；一时念头淡去会明确标注尚未确认完成。见 [生活事项](life-matters.md)。

聊天、活动和事件形成记忆，睡眠时整理。关系确认依赖真实原文，特殊关系是否允许自然形成由管理员逐类设置，见 [通讯录与关系](relationships.md)。

## 检查是否正常

| 位置 | 检查什么 |
| --- | --- |
| 控制台 | 地点、当前活动、精力与作息决定是否持续变化。 |
| 地图 | 当前活动、移动目的地、卧室是否可达。 |
| 日程 | 自动生成开关、下一次触发与实际执行结果。 |
| 内心活动 | 决定理由、心里话与复盘。 |
| 通讯录 | 当前距离、变化依据与联系受限原因。 |
| 日志 | 模型错误、超时、跳过的步骤与规则兜底。 |

普通后台模型等待默认最多 120 秒，可在设置中调整；时钟内持锁调用最多等待两秒。不同角色独立推进基本时钟。后台任务按提交顺序等待，重复工作只保留一份，并为每个角色的事项、记忆和决策保留排队空间；全局并发设置限制同时工作的数量，降低限制后，已有工作收尾，后续按新限制开始。另有每日模型预算和失败退避。部分决策、事件与日程仍持有状态锁，慢调用可能延后相关角色或日程；这部分仍需继续拆分。模型质量也会影响规划连贯性和表达。
