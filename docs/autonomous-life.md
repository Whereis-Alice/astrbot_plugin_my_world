# 自动生活指南

[文档目录](README.md) · [返回首页](../README.md)

## 一次设置，持续生活

先启用会话、选择人设、检查地图连通性，再挑选适合角色的动作。基础说话、移动、睡眠、小睡与安静闲置动作默认可用；主题动作可按角色开启，或用生成器创建。地图、动作和事件生成会先展示草稿。

新建世界默认每天当地时间 8 点之后自动生成两项安排。在“生活 → 今日 → 编辑日程”调整生成时间、数量与内容模型；已有世界保留原开关，可在这里开启。它参考当前状态、近期经历和未完的打算，生成当天的一次性计划。地图不会自动重建，生成失败时按有限次数退避重试，安静活动和作息仍继续。

生成期间手动修改日程、关闭自动生成、更换人设或生活世界，旧草稿会放弃，保留当前安排。生成跨过午夜时也会重新判断，不把昨天的草稿直接塞进新的一天。

## 日历与每日日记

在 **设置 → 记忆与资料 → 生活日历与日记** 明确选择角色所处世界：现实、同人/原作或原创。现实世界可以使用 `holidays` 提供的公共日期；同人世界优先保留原作组织、物种、历法与节庆；原创世界可以建立自己的节庆，但模型没有依据的日期会标为推定。国家代码最多八个，文化说明会直接进入生成提示词。关掉日历后，已有缓存也不会继续进入聊天或周视图。

年历按“配置范围 + 当前人格 + 年份”保存。后台维护排在生活时钟和日程之后，同一角色十分钟内最多检查一次；缺少年历时一次维护只发起一次内容生成，年历已存在时一次最多补一个仍有生活依据的日期，避免在启动或重启后连续抢占后台模型。自动日记默认在当地时间 1 点后补写前一天。日程只作原计划参考，日记正文仍以已经写入的日程记录、生活事件、事项历史与独处内心为依据；没有来源时保持空白。

聊天是否参考当天的日历与最近一篇日记，可以在同一设置中单独关闭。该内容只进入本轮动态上下文，不写入聊天历史；日历故障或日记读取失败时静默跳过，不影响正常回复。日记和年历分别按人格分区，旧记录缺少人格来源时不会拿来给当前人格补写。

## 没人聊天时

世界时钟、移动和持续活动继续推进。空闲时会观察周围、伸展休息或整理手边的小东西；这些小动作不调用模型、不发送消息，也不逐条写入记忆。可以按人设生成更多闲置动作，并调整持续时间与生活影响。

符合兴趣或探索类别的持续活动与安静闲置会留下实际投入记录，中途放下也保留；同一段活动不会重复计数，跨日期和时段分别记账。移动只负责到达地点。这些记录提供生活节奏参考，不直接认定她喜欢什么。

休息、兴趣和探索会缓解孤独与无聊，数值较高时增长放缓。同一条主动发言没有回应只计一次；她能安静做自己的事，不需要靠不断聊天维持状态。

## 作息

自主作息默认开启。她结合当地时间、精力、清醒时长、最近睡眠、人设与安排，决定何时睡以及睡多久。普通决定会等手头活动收尾，再走到卧室；待睡阶段的自动日程让位，危险事件先处理。

模型不可用、超时或给出无效结果时，按疲劳与清醒时长兜底。默认整觉范围为 6–10 小时，连续清醒达到 20 小时会触发过劳保护。也可切换固定作息。如果卧室路线损坏，她会先短暂重试；严重疲劳会立即在当前地点可用的睡眠动作休息，普通情况连续失败两次后也会回退，路线警告仍会保留供检查。控制台能看最近决定、下次评估与睡眠记录，详见 [作息与节奏](rhythm.md)。

## 安静生活与暂停

关闭顶栏“自主发言”后，普通自主规划走安静规则，抵达地点后也继续安静活动；作息评估、已安排的生活、情绪和记忆仍可运行。后台并非完全零调用：自主作息、自动排程、事件与睡眠整理有各自任务和开关。

日程提醒、事件分享及其他自主来源统一经过全局总开关与实际目标白名单；“日程到点也发言”和“事件发生时发言”可进一步限制已获授权的会话。全局关闭或白名单为空时，只保留正常回复与安静生活。白名单在“设置 → 自主发言”即时应用，旧世界升级后需要明确选择会话。插件总开关、会话停用或停止 AstrBot 会暂停生活；重新运行不会把停机期间的全部活动补演一遍。

## 打算与共同经历

她可以留下想做的事和对具体人的约定，在“生活 → 牵挂”查看跨天步骤、进展和阻碍。被打断后保留已投入时间，阶段结束后核对结果并继续后续。项目和承诺持续保留；一时念头淡去会明确标注尚未确认完成。见 [生活事项](life-matters.md)。

活动、事件和内心变化形成生活记忆，睡眠时整理；聊天原话用于人物资料和群词典，聊天往事可交给 Anamnesis 保存。关系确认依赖真实原文，特殊关系是否允许自然形成由管理员逐类设置，见 [通讯录与关系](relationships.md)。

自动与手动整理都在生活状态锁外等待模型，只把仍有效的整理字段写回；等待期间生活继续推进。成功次数随睡眠保存，失败留待重试，醒来后不把旧任务串入下一觉。

## 检查是否正常

| 位置 | 检查什么 |
| --- | --- |
| 控制台 | 地点、当前活动、精力与作息决定是否持续变化。 |
| 地图 | 当前活动、移动目的地、卧室是否可达。 |
| 生活 | 今日安排、跨天牵挂、经历与节奏依据；日程管理中查看自动生成与执行记录。 |
| 内心活动 | 决定理由、心里话与复盘。 |
| 通讯录 | 当前距离、变化依据与联系受限原因。 |
| 日志 | 模型错误、超时、跳过的步骤与规则兜底。 |

普通后台模型等待默认最多 120 秒，可在设置中调整；时钟内持锁调用最多等待两秒。不同角色独立推进基本时钟。后台任务按提交顺序等待，重复工作只保留一份，并为每个角色的事项、记忆和决策保留排队空间；全局并发设置限制同时工作的数量，降低限制后，已有工作收尾，后续按新限制开始。另有每日模型预算和失败退避。生活决策、事件生成与结算、日程编排在模型等待期间释放状态锁，返回后核对人设、日期、设置与状态；旧决定作废时保留最新生活。思考期间基本时钟继续，多角色日程独立推进。真实工具和指令的执行保持顺序，避免副作用重放；它们仍可能延后该角色的后续动作。模型质量也会影响规划连贯性和表达。
