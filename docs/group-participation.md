# 群聊参与与主动联系

小世界可以在没人点名时顺着群聊接一句，也可以继续听。角色的人设、兴趣、此刻生活和话题决定说什么；孤独与想念是感受，不是每天必须完成的联系任务。

## 从消息到开口

1. 早期监听只记下现场。晚些的接话钩子等高优先级路由处理完；已唤醒原生 Agent 的消息不另起回复。路由停止事件时尊重它的决定。直接对话仍然使用 AstrBot 原生 Agent 和工具。
2. 默认等 4 秒安静期，把连着发的几句话合起来；持续热聊最多聚合 12 秒。等待期间不占用模型工作槽，同一个共享生活组只保留一个聚合任务。
3. 只把最近 180 秒的对话看作现场，历史上下文按原设置保留。最低消息数、睡眠、精力、活动、发言冷却、每小时预算与每日联系额度共同约束接话。
4. 角色看过现场后，可选择一条短消息或空动作列表。自然的兴趣、共鸣和具体补充都可以成为开口理由。沉默也记录为一次观察，例行决策不会反复催她回答同一批消息。
5. 模型思考期间有新消息、切换人设、睡眠或人工改动时，过时结果作废。思考期间抵达的新消息在判断冷却后重新检查，过期话题不补答。平台接收后才记录发言与插话冷却；只推进实际看过的消息边界，发送期间的新消息留给下一轮。

安静且可中断的个人活动允许顺口接话，活动进度继续保留。不可中断的活动、工具执行与正在处理的对话会优先完成。

## 各模块怎样配合

| 入口 | 共同约束 |
| --- | --- |
| 新消息接话、例行插话、想念找人、陪伴动机、主动分享、早晚问候、动作续说、戳一戳 | 共用实际发送节奏、联系额度及未回应联系人等待；同一联系的即时发送和收尾只算一次。 |
| 日程与事件 | 保留各自发言开关和投递目标；已发出的内容也计入最近发言，让其他主动模块先留白。事件决策能看到投递现场，求助围绕具体事情，允许不分享普通经历。 |
| 直接回应 | 保留原生 Agent、工具和回复；回复完成会通知其他主动模块暂时留白，不消耗主动找人额度。 |

默认主动开口前留白 90 秒；某个联系人未回应时，至少等待 6 小时再主动联系，等待在同一个共享生活组内跨群聊与私聊生效。明确回应她会解除对这个人的等待；只是在群里说别的话不会清除等待，也不会被算成陪她聊天。

短时同一联系可以发送后续句子，不能用一个旧计划标识无限延续联系。发送失败不计入联系次数、插话冷却或已回应水位。沉默标记和空 JSON 动作不会被当成台词外发。

## 设置与检查

打开 **设置 → 聊天与表达 → 群聊参与与分寸**，可调整消息接话开关、现场窗口、聚合等待、判断间隔、主动留白与联系人等待。关闭顶栏「自主搭话」仍然保留安静生活、直接回应以及日程和事件各自的开关。

默认每次接话判断至少间隔 60 秒，继续使用现有自主文本次数、后台并发及 token 预算，没有新增独立无限调用通道。控制台显示最近是旁听还是接话；模型调用页可筛选「群聊参与判断」。原有 `/mw` 命令和数据继续兼容，`/小世界` 管理命令不会混进对话。

已有测评接口 `eval-run` 可用 `variant: "participation"` 对合成群聊做只读模型测评，不发送群消息、不推进角色状态；它用于检查角色是否自然接话或选择沉默，不模拟真实平台投递。

## 参考

研究了 [SpectreCore](https://github.com/23q3/astrbot_plugin_SpectreCore/tree/dd9218cd08cef1bc5ed1f6f6cb970710cefb3977) 的群聊历史、并发排他、读空气及原生人格/工具整合思路。小世界采用独立实现，将这些思路接入已有生活状态、共享会话、发送回执和预算机制；未复制其源代码。没有引入逐消息随机回复或另一套聊天人格。
