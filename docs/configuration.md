# 全局与会话配置

[文档目录](README.md) · [返回 README](../README.md)

v3.1 起，通用配置默认由所有会话继承；需要差异时，再为某个会话启用独立配置。
升级会保留已有地图、动作与日程，旧会话默认继续继承，不会自动复制出多套库。

## 暂停自主搭话

编辑器顶部的「全局自主搭话」开关立即生效，不需要再点保存。

| 关闭后 | 行为 |
| --- | --- |
| 自主找人、插话、想念时搭话、自主动作续说 | 暂停；尚未发送的自主发言也会被拦住 |
| 日程提醒、日程动作链及其后续发言 | 保留 |
| 事件求助、事件进展和结果 | 保留 |
| 被 @ 或正常收到消息后的回复 | 保留，继续遵循原有唤醒与会话规则 |
| 移动、休息、内部动作、情绪、记忆与心思 | 继续运行 |
| AstrBot 原生工具和其它插件的发言 | 不受此开关控制 |

每套「设置 → 基础」里还有「允许自主搭话」。它可以单独关闭当前配置范围的自主搭话，
但不能越过顶部全局暂停。重新开启全局开关，也不会把会话里单独关闭的选项强制打开。
日程发言只要原本已经安排好，就会继续；从日程睡醒后产生的问候也属于日程后续。

## 编辑范围

顶部两个选择器各有用途：

- **会话**：观察与操作对象，例如查看状态、记忆、事件，或手动运行一条日程。
- **编辑范围**：地图、动作库、日程与设置保存到哪里。默认选择「全局默认」。

选中一个会话后，未独立的页面显示「继承全局」且只读。勾选「本页单独配置」，
以当前生效配置为起点修改，再点保存。生成区域、动作或日程得到的草稿也保存到当前编辑范围。
切换范围前如果有未保存修改，会提示是否放弃；取消后可以先保存。

| 配置块 | 包含内容 |
| --- | --- |
| 地图 | 区域、地点、区域内连线与跨区连线 |
| 动作库 | 全部动作及分组、已清除动作的记录 |
| 日程 | 完整日程列表和每条日程的目标、时间、动作链 |
| 设置 | 人格、世界规则、情绪、事件规则、记忆规则、作息、名片与其它通用世界设置 |

**独立的是整个配置块**。例如只独立动作库，地图和日程仍跟随全局；
之后全局新增动作，不会自动追加进已独立的动作库。需要协调地图和动作使用的地点，
以及日程引用的动作 ID；保存时出现的配置提醒应一并检查。

取消「本页单独配置」并保存，会移除该块的独立版本，恢复使用最新全局配置。
这不会合并两个版本，也不会删除角色的位置、记忆或生活状态。写入前会保留配置历史。

管理员、全局暂停、会话与共享生活组管理、配置预设和恢复默认等管理功能仍属于全局。
已发生的事件、记忆与状态是运行数据，不通过配置继承互相复制。
插件详情中的模型槽位与基础运行参数也仍是插件级设置。

## 共享生活组

已编入共享生活组的群和私聊代表同一个角色，因此一起使用**组主会话**的配置。
编辑范围会将它们显示成一个会话组，生活时钟与日程只推进一次。
暂时停用主会话不会把配置切换成另一个成员的版本。

成员在入组前已有的独立配置仍保留；在组内暂不使用，离组后重新生效。
修改组主会话会更换配置来源。需要每个群独立地图与日程时，应保持它们为独立会话。

## 日程示例

所有群都用同一套作息：在「全局默认 → 日程」里修改，其它会话保持继承。
只有 A 群作息不同：选择 A 群，进入日程，勾选单独配置并保存。
此后 A 群使用自己的整套日程，其它会话继续使用全局日程。

Bot 自己添加、删除或回收一次性日程时，也会写回实际使用的那套日程：
继承者写全局库，独立会话写自己的库。日程的目标会话限制仍然有效；
全局库中的提醒若只想给某个群，应在该条日程中指定目标。
