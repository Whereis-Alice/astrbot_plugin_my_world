# 我的世界 MW

为 AstrBot 角色建立持续运行的生活：她有自己的住处、作息、情绪、计划和人际关系。即使没人聊天，世界也会继续推进；有人找她时，这些经历会成为回复的背景。

![version](https://img.shields.io/badge/version-v4.8.0-4f6bf5)
![AstrBot](https://img.shields.io/badge/AstrBot-%E2%89%A5%204.20.0-8b6cf0)

需要 **AstrBot 4.20.0 至 4.x**，使用 AstrBot 自带依赖，无需额外安装 Python 包。

地图和动作构成角色的虚拟生活。例如“去书房看书”会改变地点、时间、状态与记忆。聊天回复和真实工具调用继续使用 AstrBot 原生 Agent，可与世界书、记忆、视觉、语音和输出增强插件配合。

本项目基于 exneverbur 的 [astrbot_plugin_virtual_world](https://github.com/exneverbur/astrbot_plugin_virtual_world) 二次开发，历史名称为 `astrbot_plugin_her_world`。心迹画像的相关实现来自 [astrbot_plugin_profile_weaver](https://github.com/Whereis-Alice/astrbot_plugin_profile_weaver)。来源与许可见 [NOTICE](NOTICE.md)。

## 先让她生活起来

1. 在 AstrBot 中安装本仓库并启用，配置好可用的聊天模型。
2. 在需要启用的群聊或私聊发送 `/mw session add`。只有加入白名单的会话会运行这个世界。
3. 打开 **AstrBot 面板 → 插件 → 我的世界 MW → 我的世界编辑器**。
4. 在“设置 → 她是谁”选择角色人设。可以使用 AstrBot 当前会话的人设。
5. 在“地图”配置住处和地点，或使用“生成区域”“一键重建地图”。模型生成后会先展示草稿，确认才保存。
6. 在“日程”生成或添加基础作息。希望她每天自行安排活动时，开启日程页的 **自动生成**，设置生成时间和每天条数。
7. 在“控制台”查看当前状态，发送 `/mw status` 或和她聊几句确认效果。

完成首次配置后，时钟、动作推进、状态变化、作息、事件和睡眠整理会自动运行。**自动排程需要单独开启**；世界生成按钮用于初始搭建和后续调整，不会每天自行重建地图。

## 她会做什么

| 能力 | 实际行为 |
| --- | --- |
| 日常生活 | 按时间、精力、无聊和好奇等状态选择移动、休息或活动；正在做的事会持续推进。 |
| 每日安排 | 自动排程参考当前时间、地点、精力、最近经历和未完的心事，生成少量一次性计划。执行后自动移除。 |
| 情绪与内心 | 对话和经历改变心情，留下计划理由、心里话和复盘记录，可在“内心活动”查看。 |
| 记忆与关系 | 记住共同经历，维护称呼、偏好、好感和关系变化；睡眠时整理积累的信息。 |
| 事件 | 世界事件可以触发后续行动；地图、地点、动作和事件均可在编辑器调整。 |
| 自主交流 | 她可以想起某个人、接话或分享经历，受到发言开关、冷却和次数限制。 |

发言冷却或自主行为额度用尽时，她仍可按规则走动、休息和恢复精力；这类安静活动不会调用规划模型，也不会在稍后完成时突然补发活动旁白。

自动排程遇到网络或模型故障时，每个配置范围每天最多尝试 3 次；前两次失败分别等待 15、45 分钟。成功保存计划后，当天不再重复生成。独立日程配置有自己的生成记录，继承全局日程的会话共用全局安排。

## 通讯录与画像

![通讯录示例](docs/images/contacts.png)

通讯录将原心迹画像与本插件的人际数据放在同一个联系人下：

- **认识与经历**：一句话印象、稳定画像字段、画像备注、共同经历、近期变化和约定。已有结构化字段的旧导入副本不再重复显示，原始数据仍保留。
- **关系**：当前关系、曾经的关系、好感度、想念状态与她记着的事情。
- **模型可见资料**：预览这个联系人作为当前说话人时提供给模型的资料，方便核对注入内容。
- **总览、审计、数据与备份**：字段覆盖率、改动依据、历史、导入导出、脱敏导出和备份维护。

桌面上联系人列表与详情正文分别滚动，姓名和详情页签固定可见。手机上先选人，再进入详情，使用“← 联系人”返回。

### 数据如何合并

默认 **按会话隔离画像**。同一个人在其他群和私聊的专属记录不会混进当前会话。明确的全局共享字段可作为补充；同名字段优先使用当前会话的值。带“全局共享”标记的字段和备注会修改原始共享记录，影响使用它的会话。共享生活组中的关系、好感和经历按生活组管理，画像字段仍遵循画像的会话设置。

当前说话人的关系、事实与字段资料会自动注入请求；近期参与聊天的其他人只提供简短背景。称呼、画像备注和摘要都可能供模型参考。字段锁、原文依据和变更历史继续保留。

需要主动查资料时，模型可使用 **`mw_profile_lookup`**：

| 参数 | 用途 |
| --- | --- |
| 不传参数 | 查询当前消息发送者的画像、关系与经历。 |
| `query` | 按称呼或用户 ID 查当前会话可见的联系人；同名时先返回候选 ID。 |
| `user_id` | 按明确的用户 ID 查询，优先于 `query`。 |
| `topic` | 可选关键词，如“生日”“爱好”“面试”，筛选字段和经历。 |

模型可以在选择礼物、核实偏好、回忆约定等场景主动调用，无需用户先说“查询画像”。工具只读；没有记下的事会返回缺少记录。需要在 AstrBot 中启用该工具，并使用支持工具调用的模型。

原工具 `profileweaver_view_profile`、`profileweaver_remember_field`、`profileweaver_forget_field` 继续兼容。写入和删除仍要求当前发送者的明确自述或请求，并校验本轮原话、字段锁与身份冲突。读取画像不会阻止本轮后续的自动信息提取。

### 从心迹画像迁移

首次启动会从旧插件数据目录继承画像、字段锁、审计和备份。升级前建议保留 AstrBot 数据目录备份；升级后在通讯录中核对几位联系人及其会话范围。

确认记录正常后，可停用旧画像插件，只保留本插件。旧插件仍启用时会避免重复注册其三个同名工具与重复注入；新增的 `mw_profile_lookup` 保持独立。旧数据后续有变化时按字段增量同步；未变化的旧字段不会在每次重启时重新导入。

详细规则与指令见 [记忆与通讯录](docs/memory.md)。

## 控制她在哪生活、何时开口

编辑器顶栏中的两个选择器用途不同：

- **会话**：选择查看哪个群或私聊的状态和日志。
- **编辑范围**：选择修改全局默认配置，还是某个会话的独立配置。

地图、动作库、日程、设置可分别继承全局，也可在对应页面开启“本页单独配置”。共享生活组共用同一个角色状态，跨群发言不会重复推进生活时间。详见 [配置范围](docs/configuration.md)。

顶栏 **自主搭话** 开关控制主动找人、插话和自主动作续说。关闭后，生活、情绪和记忆仍推进。日程提醒与事件发言各有开关；希望她只回应别人时，同时关闭设置中的“日程到点也发言”和“事件发生时发言”。

插件总开关关闭或会话被停用时，该范围的生活也会停止运行。不要把“暂停主动发言”与“停用插件”混为一谈。

## 常用指令

默认指令前缀为 `/mw`，也可写 `/我的世界` 或 `/myworld`。如果改过 AstrBot 唤醒前缀，请替换示例中的 `/`。

| 指令 | 作用 |
| --- | --- |
| `/mw status` | 查看地点、活动、心情和状态。 |
| `/mw session add` | 启用当前会话。 |
| `/mw memory`、`/mw recall <话题>` | 查看记忆、按话题回忆。 |
| `/我的画像`、`/设置画像 <字段> <值>` | 查看或修改自己的画像。 |
| `/画像字段`、`/画像历史`、`/画像帮助` | 字段目录、改动历史和完整画像指令。 |
| `/mw profile` | 通讯录画像统一入口；支持字段、锁、历史等子命令。 |
| `/mw forget me [话题]` | 忘记自己的相关记忆。 |
| `/mw event <一句话>` | 安排一件会发生的事。 |
| `/mw schedule`、`/mw map` | 查看日程或地图。 |
| `/mw help` | 完整指令与管理员操作。 |

## 模型与插件配合

主回复使用 AstrBot 当前会话的模型和原生工具流程。插件配置中的“插件用主模型”用于自主决策等后台请求；“内容生成模型”用于地图、动作、日程和事件生成；睡眠整理模型用于记忆与画像整理。未单独配置的模型按配置说明回落。详见 [模型选择](docs/models.md)。

默认 `reply_mode=inject`：插件注入角色处境，保留原生工具集、对话历史和其他插件追加的上下文。输出分段、引用、表情包、语音与视觉仍走相应插件。`takeover` 和旧版工具动作仅用于旧数据兼容，新的配置建议使用默认模式。

地图与动作属于虚拟世界；需要查天气、联网搜索或操作外部服务时，请在 AstrBot 配置对应工具。详见 [插件联动](docs/integration.md)。

## 遇到问题

| 现象 | 优先检查 |
| --- | --- |
| 她不回复 | 会话是否启用、是否睡着、是否命中回复门禁；查看控制台与日志。 |
| 她不主动开口 | 自主搭话开关、无人回应冷却、频率与额度；生活活动仍可能正常进行。 |
| 每天没有新安排 | 日程页是否开启自动生成、是否到设定时间、内容生成模型是否可用；查看生成失败日志。 |
| 某人的资料缺少内容 | 确认当前会话范围，在“模型可见资料”和数据来源中核对。 |
| 模型不用画像工具 | 确认画像工具开关、AstrBot 工具启用状态和模型的工具调用能力。 |
| 生成地图或日程失败 | 编辑器会保留错误与草稿状态。检查 Provider、额度、超时和返回格式后重试。 |

数据默认保存在 `data/plugin_data/astrbot_plugin_my_world/`，包括世界配置、SQLite 状态库和 `profile_weaver/` 画像目录。从更早的世界插件迁移，可在首次启动前设置 `MY_WORLD_MIGRATE_FROM=<旧数据目录>`；已有数据不会被整份覆盖。
