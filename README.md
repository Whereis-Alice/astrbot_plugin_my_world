# 小世界

给 AstrBot 角色一个持续运行的生活。她有自己的住处、作息、心情、打算和人际关系；没人聊天时，也会休息、观察周围、做些小事。再和她说话时，这些经历会成为她的背景。

适用于 **AstrBot 4.28.2 至 4.x**。插件依赖使用 AstrBot 的插件依赖安装流程处理；`holidays` 用于公共日历候选，缺失时会安全降级为模型推定。地图与活动是角色的虚拟生活；联网、查天气、生图等真实操作使用 AstrBot 中已配置的工具。

![小世界 · 生活观测站](docs/images/webui-observatory.png)

六种独立光影主题：[星屿、潮汐、晚樱、晴空、日晷、竹间](docs/images/webui-worlds.png)。[查看手机效果](docs/images/webui-observatory-mobile.png)与[界面说明](docs/webui.md)。

## 先让她生活起来

1. 在 AstrBot 插件管理中，通过仓库地址安装本插件，并配置可用的聊天模型。
2. 在需要启用的群聊或私聊发送 `/mw session add`。只有加入的会话会运行世界。
3. 打开 **AstrBot 面板 → 插件 → 小世界 → 插件页面**。
4. 在 **设置 → 她是谁** 选择角色人设；在地图和动作库中调整她的住处与日常活动。也可以按人设生成内容，检查草稿后保存。
5. 新建世界默认在每天当地时间 8 点之后自动安排两项活动；在 **生活 → 今日 → 编辑日程** 调整时间与数量，在 **生活 → 经历** 调整随机经历的频率。自主作息默认开启，她会结合精力和生活决定何时休息。
6. 保存配置，在 **控制台** 查看地点、活动和心情，再和她聊几句。
7. 需要她主动参与时，在 **设置 → 自主发言** 为群或私聊勾选「主动发言」，点 **应用全局白名单**。希望她主动讲自己的生活，再额外勾选「生活分享」；升级后这项授权默认留空。安静生活和正常回复照常。

首次设置完成后，时间、活动、情绪、作息、闲置生活和睡眠整理会自动推进。已有世界保留原来的自动排程开关，可在日程管理中开启；地图不会每天自行重建。AstrBot 需要保持运行，停机期间不会补演全部活动。

每天的新念头会参考近期个人事项，保留已完成、暂停和等待的来由；没有新方向时可以留白。情绪只是此刻的倾向，原有人设、相处边界与眼前的话题决定她怎样回应。

跨天项目在完成小步后，会在空闲时留下具体小结和本次想到的话，保留尚未解决的问题与后续安排。默认每个生活世界每天最多调用两次小结生成，失败也计入；在 **生活 → ⋯ → 节奏与预算…** 或 **设置 → 生活与作息 → 生活事项** 中调整，设为 0 可关闭。小结只写入自己的生活记录，不自动发送聊天消息。

**不需要睡觉的角色**，可以在作息设置选择“无需睡眠，通过活动恢复”，指定充电、维护或冥想动作。恢复会遵守地点与实际时长，按效果恢复精力；生成的整觉、小睡也能参与睡眠机制。配置示例见 [角色的恢复方式](docs/recovery.md)。已有世界保留当前模式，需要明确切换。

**保留地图重新设计活动**：地图工具栏有“只重做动作…”，区域和地点侧栏分别有“重做区域动作…”与“重做地点动作…”。可设置每地点数量、分组方式与额外提示词，整批生成后预览确认，覆盖对应的专属动作和分组。详见 [重做地点动作](docs/webui.md#保留地图重做动作)。

问起生活进展时，已结束的事项按最新结果回应，旧计划不再作为当前待办；暂停的事项保留书签、未解问题和接续位置，等真正继续时再推进。

等待和受阻的项目也会保留接续位置，说明当前还没有继续做。中断或重载后，已经计满投入的小步可恢复登记并进入复核，未确认的发现和现实约定不会因此变成已完成。

每日排程会参考已保存的今日文化日历与最近日记，接续前一天的生活；遵循“生活上下文”开关。慢速模型等待不会阻止基本时钟与状态编辑，失败的日历、日记和排程会有限重试，期间规则生活继续。

“生活”入口将 **今日、牵挂、经历、周视图** 放在一起：看一天的安排、接续跨天打算、回顾发生过的事，并在同一周里对照日程、现实/虚构世界日历与每日日记。四者怎样配合，见 [生活工作区](docs/life-workspace.md)；完整设置见 [自动生活指南](docs/autonomous-life.md)。

## 她的世界里有什么

| 内容 | 能做什么 |
| --- | --- |
| 地图与活动 | 在地点之间移动，持续看书、休息或做事；空闲时轮换安静的小动作。 |
| 作息与日程 | 自己评估睡眠，按安排生活，也可每天自动生成少量计划。 |
| 日历与日记 | 为现实、同人或原创世界维护年历与文化背景；按已完成的生活记录写第一人称日记。 |
| 生活事项 | 把自己的打算拆成跨天的小步，记住进展和阻碍；被打断后继续，阶段结束后再安排后续。 |
| 情绪与内心 | 经历影响心情与需求，保留当时的想法、未完的打算和复盘。 |
| 事件 | 遇见日常小事或更复杂的经历，作出选择，留下后续影响。 |
| 生活记忆 | 记录她的活动、事件、内心与实际进展；梦与现实分开。 |
| 通讯录与群词典 | 自动整理人物事实、详细画像和共同用语，保留关系与好感的来由。 |
| 网页编辑器 | 查看她此刻在做什么，编辑世界，检查行为理由与记录；支持六套独立光影主题。 |

她的独处生活不需要群友一直陪聊。休息、兴趣和探索会缓解需求；主动说话没人回应时，她也会安静下来。后台模型不可用时，基本活动与作息有规则兜底，丰富的规划和整理仍需要可用模型。

**内心活动** 也会保留动作完成后的续说、动作台词生成时模型给出的心里话，分别标为“动作结束后”和“准备说话”，按当时的会话显示。她决定保持安静时也可以留下想法；模型没有提供内心描述时，不会从台词反推或补造记录。新消息接话和计划接话也会在同次请求中留下简短想法；内心详情与发言日志关联触发原因、意图、引用和真实发送结果，失败或过期不会记成已经说过。详见 [主动发言与内心记录](docs/proactive-speech.md)。

也可以让她偶尔 **翻翻手机或电脑里的近期消息**，留下一点自己的感受，随后继续生活。默认只安静阅读；可另行开启“浏览后允许她判断是否接话”，按当前话题接一句，是否接话始终由她自行决定。点击 **生活页顶栏的「手机与电脑」** 配置设备、阅读量和开关；在 **内心活动 → 翻消息时** 查看感想、浏览进度和等待原因，详见 [安静翻消息](docs/chat-browsing.md)。

在 **生活 → 牵挂** 可以查看她惦记的事情、下一步和生活经过，也能暂停、延期或调整事项。中途书签保留实际投入、未解问题和接续位置，阶段笔记留下已有成果；聊天按话题选取，并把旧进展与最新状态一起理解。编程、创作、整理收藏等个人活动可以由 AI 在她的世界里模拟推进，无需配置电脑环境。模拟经历会明确标注，对现实用户的约定仍需实际兑现。困意、事件、日程和精力共同影响安排，原有人设始终优先。详细规则见 [生活事项](docs/life-matters.md)。

生活记忆的回想方式与可选嵌入模型在 **设置 → 记忆与资料 → 生活记忆** 中调整；可以直接选择 AstrBot 已配置的嵌入模型，详见 [生活记忆](docs/memory.md)。**生活日历与日记** 也在同一分类：可明确选择现实、同人/原作或原创世界，设置国家代码、文化说明、日记生成时刻与保留数量，并单独关闭“把日历与最近日记注入聊天”的可选上下文。

## 关系如何发展

插件把 **身份关系、好感、相处距离和行为边界** 分开管理。例如，“朋友”是关系，好感表示感觉，当前档位描述相处距离；具体言行仍遵循原有人设。生气时可以暂时疏远，不会因此直接解除关系。

- 普通友谊默认会随跨日期的直接交谈与好感逐渐发展，群内刷屏不会累积交谈日期。
- **恋爱、主人等特殊关系默认只允许管理员手动设置**。在“关系与好感 → 管理 → 关系规则”中可逐类开启自然形成；开启后也需要实际交谈依据与她的确认。
- 每种关系可设置距离上下限、唯一性和是否允许越过通常上限。距离更近不会自动改变身份。
- 档位可自由编辑，也可使用 **十档相处方案**：戒备、疏远、礼貌、初识、熟悉、投缘、信任、亲密、知己、相依。
- 关系与档位默认只提供背景；**额外说明、禁止动作都可留空**。需要限制时，按名称搜索、勾选已启用的动作即可。
- **关系与好感** 是独立页面，按 QQ 号汇总人物卡片。可以一起设置好感和多个身份，保存后应用到所有会话，并作为未来新会话的起点；之后各会话独立发展。
- **通讯录** 用人物卡片展示称呼、资料与共同经历，点开即可管理完整档案。关系页可查看各会话的当前距离、变化依据和联系限制。

如何设置、确认关系与理解边界，见 [通讯录与关系](docs/relationships.md)。

她也会从具体交谈中积累相处方式和共同用语。**原有人设始终是言行的主要依据**，经验不会改写身份、性格、价值观或原有喜恶。可在通讯录查看互动依据，在记忆页维护会话词典，详见 [相处习惯与共同用语](docs/social-learning.md)。

## 控制她什么时候开口

顶栏的 **自主发言** 开关统一控制全部自主发言，包括找人、插话、问候、日程、事件与自主动作续说。关闭后，她继续安静生活，也会回应符合设置的消息。

在 **设置 → 自主发言** 应用全局会话白名单，并统一调整每日联系总上限与对单个人的上限。只有名单内会话能收到自主发言。次数只在发送成功后计算；相处档位不规定每天必须或最多联系几次。

「生活分享」是额外的全局白名单，可单独授权群聊或私聊。没有这项授权时，她仍可接当前话题、找人，也会在被问到时回答自己的近况；自己的动作进展、成果、早晚安、日程和事件不会突然广播。普通生活动作的完成续说也受这项授权限制，活动本身与记忆照常推进。

**群聊参与与分寸** 提供新消息接话：等群友连着说完，按参与程度留意现场，再结合人设与话题生成回应。**自然沉默默认关闭**；开启后，才允许因没话想说而继续旁听。新消息接话与浏览后接话共用这一设置。近期现场与历史上下文分开，旧话题不会被当成正在聊；刚回应过、刚分享过日程或事件时，其他主动入口会先留出空间。某人没有回应时，跨群聊与私聊共用等待，避免换个地方继续追问。详见 [群聊参与](docs/group-participation.md)。

希望只回复别人时，关闭顶栏 **自主发言**。希望保留接话、找人而不主动讲生活，则保持「生活分享」名单为空。插件总开关或会话开关会停止相应范围的生活，与暂停搭话用途不同。多个群与私聊可以分别生活，也可以通过共享生活组共用一份状态，详见 [配置范围](docs/configuration.md)。

## 常用指令

示例使用 AstrBot 默认唤醒前缀 `/`；更改过前缀时请相应替换。`mw` 也可写成 `小世界`、`我的世界` 或 `myworld`。

| 指令 | 作用 |
| --- | --- |
| `/mw status` | 看她在哪、在做什么、心情如何。 |
| `/mw session add` | 启用当前会话。 |
| `/mw memory`、`/mw recall <话题>` | 看记忆，或按话题回忆。 |
| `/我的画像`、`/设置画像 <字段> <值>` | 查看或修改自己的资料。 |
| `/mw profile` | 通讯录与画像指令入口。 |
| `/mw schedule`、`/mw map` | 查看日程或地图。 |
| `/mw event <一句话>` | 安排一件事。 |
| `/mw help` | 查看完整指令。 |

## 模型与其他插件

聊天回复使用 AstrBot 原生 Agent。插件提供人设、此刻处境与生活记录，模型调用、工具执行和消息发送由宿主处理；世界书、记忆、视觉、语音和表情包插件可继续配合使用。后台规划、内容生成与睡眠整理可分别选择模型，见 [模型设置](docs/models.md) 和 [插件联动](docs/integration.md)。

My World 的记忆库专注她自己的生活，人物事实、详细画像和群词典完整保留。聊天往事可交给 Anamnesis 等长期记忆插件，两边各自管理数据，见 [记忆共存说明](docs/memory-compatibility.md)。

编辑器的 **模型调用** 页面可查看调用原因、触发路径与已返回的 Token 用量。后台可设置每日预算；记忆可展开查看来源原话，并按需开启语义召回，详见 [模型调用与用量](docs/model-calls.md) 和 [记忆与通讯录](docs/memory.md)。小内存服务器可参考 [资源设置建议](docs/resources.md)。
